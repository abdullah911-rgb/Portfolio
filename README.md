## 📄 Dedicated CV / Resume Section

The portfolio includes an interactive **CV / Resume section** (`#resume`) where recruiters and visitors can:
1. Preview the CV directly inside an interactive card
2. Switch to an inline embedded PDF viewer
3. Download the PDF directly with one click
4. Open the PDF in a clean browser tab

### 🔄 How to Update / Re-upload Your CV Anytime
To update your CV with zero code changes:
1. Save your new resume PDF with the exact name **`resume.pdf`**
2. Put it in:
   ```
   public/assets/resume.pdf
   ```
3. Commit and push to GitHub:
   ```bash
   git add public/assets/resume.pdf
   git commit -m "update: latest CV"
   git push
   ```
4. **Vercel will automatically detect the push and deploy your new CV live in ~30 seconds!**

## ☁️ How to Deploy Free on Vercel (Step-by-Step)

Deploying this portfolio on [Vercel](https://vercel.com/) is **100% free** and takes less than 2 minutes:

### Step 1: Sign in to Vercel with GitHub
1. Go to **[https://vercel.com](https://vercel.com)**
2. Click **Sign Up** (or Log In) and choose **"Continue with GitHub"**
3. Authorize Vercel to access your GitHub repositories

### Step 2: Import Your Repository
1. In your Vercel Dashboard, click the **"Add New..."** button (top right) → select **"Project"**
2. You will see a list of your GitHub repositories
3. Find **`Portfolio`** (`abdullah911-rgb/Portfolio`) and click **"Import"**

### Step 3: Configure & Deploy
Vercel automatically detects Vite and configures everything:
- **Framework Preset:** `Vite` (auto-detected)
- **Root Directory:** `./`
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Install Command:** `npm install`

*(No environment variables are needed)*

Click **"Deploy"**!

### Step 4: Your Site is Live! 🎉
- In ~45 seconds, Vercel will build and provide your free live URL, like:
  ```
  https://portfolio-xxxx.vercel.app
  ```
- **Instant CI/CD:** Every time you push a commit or update your resume PDF on GitHub (`git push`), Vercel will automatically redeploy the latest version.
